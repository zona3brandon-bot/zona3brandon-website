# Zona 3B Brandon — Web V5.5

Diseño basado en la referencia aprobada, usando el logo oficial de Zona 3B.

## Cambios
- Nuevo servicio de envío de dinero a Cuba.
- Enlace en el menú y botón destacado en la portada.
- Nueva sección informativa con acceso directo a WhatsApp.
- Mensaje automático para solicitar información sobre envíos de dinero.
- La imagen de fondo muestra solamente La Habana, el barco y el avión.
- Se eliminaron del fondo los textos y paneles duplicados.
- Logo oficial actualizado.
- Panel transparente y calculadora flotante.
- Carrusel de ofertas de cajas.
- Diseño responsive.
- Caché optimizada para Cloudflare Pages.
